​	使用 rio rgbify 进行高程切片。

##### 一、Windows 平台安装环境

```
// 安装 gdal 库，使用 Conda 安装方便很多
conda install conda-forge::gdal

// 安装 rasterio
pip install rasterio

// 安装 rio-rgbify
pip install rio-rgbify
```

##### 二、相关命令

```
// 查看栅格信息
rio info demo.tif

// 投影转换
gdalwarp -t_srs EPSG:3857 -dstnodata None -co TILED=YES -co COMPRESS=DEFLATE -co BIGTIFF=IF_NEEDED input.tif output.tif

```

> 如果 input.tif 太大，`IF_NEEDED` 要改成 `YES`

##### 三、开始切片

```
// 示例代码
rio rgbify -b -10000 -i 0.1 --co=BIGTIFF=IF_NEEDED input.tif output.tif
```

> 如果 input.tif 太大，`IF_NEEDED` 要改成 `YES`。-10000 表示最低点，如果有更低的地形，需要修改这个，否则数值会反转。

##### 四、注意事项

> 目前测试 `mapbox` 只支持 `3857` 投影，其他暂未测试。

##### 六，使用示例

```js
// mapbox 附带账户和密码访问 geoserver
map = new mapboxgl.Map({
    container: 'map', // container ID
    center: [110.566076, 17.374748], // starting position [lng, lat]. Note that lat must be set between -90 and 90
    zoom: 3, // starting zoom
    antialias: true,
    projection: 'globe', // equirectangular globe mercator naturalEarth
    maxZoom: 24,
    dragRotate: true,
    touchRotate: false,
    style: {
        "version": 8,
        "name": "Mtr1994",
        "sources": {
            "raster001": {
                "type": "raster",
                "tiles": ["http://10.10.39.178:8080/geoserver/gwc/service/wmts/rest/ougp:world/EPSG:900913/EPSG:900913:{z}/{y}/{x}?format=image/jpeg"],
                "tileSize": 256
            }
        },
        "layers": [{
            id: 'background',
            type: 'background',
            paint: {
                'background-color': 'rgb(254, 254, 254)'
            },
        }
                   , {
                       "id": "layer001",
                       "type": "raster",
                       "source": "raster001"
                   }]
    },
    config: {
        basemap: {
            theme: 'monochrome'
        }
    },
    transformRequest: (url, resourceType) => {
        if (url.startsWith('http://192.168.150.128:8080')) {
            return {
                url: url,
                headers: { 'Authorization': 'Basic ' + btoa('cm:123456') }
            }
        }
    }
});

// mapbox 添加高层图层
map.on('load', () => {
    map.addSource('mapbox-dem', {
        'type': 'raster-dem',
        'tileSize': 256,
        'tiles': ["http://192.168.150.128:8080/geoserver/gwc/service/wmts/rest/ougp:demo38573/EPSG:900913/EPSG:900913:{z}/{y}/{x}?format=image/png"]
    });
    map.setTerrain({ 'source': 'mapbox-dem', "exaggeration": 10 });
});
```
