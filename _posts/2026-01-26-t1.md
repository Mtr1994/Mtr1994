​	使用 ctb-tile 进行高程切片。

##### 一、Linux 下安装 Docker

```
sudo  apt install docker
```

##### 二、相关命令

```
// 查看有哪些容器（包括已经停止的）
sudo docker ps -a

// 关闭容器
sudo docker stop <容器ID或名称>

// 启动容器
sudo docker start <容器ID或名称>

// 删除容器
sudo docker rm <容器ID或名称>

// 获取并启动容器
sudo docker run -it --name ctb  -v "/home/mtr1994/Documents/website/terrain:/data" ghcr.io/tum-gis/ctb-quantized-mesh:latest
```

##### 三、开始切片

```
// 示例代码
// ctb-tile -f Mesh -C -N -o terrain tiles.vrt            # Create terrain files
// ctb-tile -f Mesh -C -N -l -o terrain tiles.vrt         # Create layer description file

// 切片，输出到 cesium 目录下
ctb-tile -f Mesh -C -N -o ./cesium map.tif
// 生成图层描述文件
ctb-tile -f Mesh -C -N -l -o ./cesium map.tif
```

> 切片的投影是什么好像没有关系，Cesium 会自动对照？（测试发现 4326 的 terrain 文件 和 3857 的表面图层居然可以对的上），格式好像也可以选其他的，不一定是这个。

##### 四、注意事项

> .terrain 文件默认是开启了 gzip 的，如果直接通过文件服务访问，会发生 `RangeError: Invalid typed array length: 4225` 错误。测试采用的方法是通过 `Nginx` 发布，添加头信息

##### 五、使用示例

```js
const viewer = new Cesium.Viewer('cesiumContainer', {

});

// 添加地形数据
const addWorldTerrainAsync = async (viewer) => {
    try {
        const terrainProvider = await Cesium.CesiumTerrainProvider.fromUrl(
            "../../cesium",
            {
                requestWaterMask: true,
                requestVertexNormals: true,
            }
        );
        viewer.terrainProvider = terrainProvider;
        const scene = viewer.scene;
        scene.verticalExaggeration = 10.0;
    } catch (error) {
        console.log(`Failed to add world imagery: ${error}`);
    }
};

addWorldTerrainAsync(viewer);

var imageryProvider = new Cesium.WebMapTileServiceImageryProvider({
    // 这里是你的 geoserver服务点击查看图层的 url
    url: 'http://10.10.39.178:8080/geoserver/gwc/service/wmts/rest/ougp:world/{TileMatrixSet}/{TileMatrixSet}:{TileMatrix}/{TileRow}/{TileCol}?format=image/jpeg',
    // 这里是自定义的图层名称
    layer: 'ougp:world',
    style: 'default',
    format: 'image/jpeg',
    tileMatrixSetID: 'EPSG:4326',
    tilingScheme: new Cesium.GeographicTilingScheme()
});
// 图层添加
viewer.imageryLayers.addImageryProvider(imageryProvider);
```

> 注意 `CesiumTerrainProvider` 的 `url` 是相对于文件服务根目录的地址，好像不能用完整地址。（可以测试）
